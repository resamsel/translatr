# Cypress / Nx / Angular Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get `ui/`'s `cypress` to the latest release (15.x) through the supported `@nx/cypress@23` executor, which requires migrating the whole Nx workspace 19 → 23 and Angular 19 → 21 in staged, individually-green passes.

**Architecture:** Five sequential migration passes, each its own commit behind a full verification gate. Nx platform first (19→20, no framework change), then two Angular-major passes (→20, →21) driven by `nx migrate`, then Cypress 13→15 plus both e2e projects onto `cypress.config.js`, then cleanup. Non-Nx Angular libraries (`@ngrx/*`, `@fortawesome/angular-fontawesome`, jest ecosystem, spectator, transloco) are bumped by hand within each pass to the release line matching that pass's Angular major. A documented fallback (Nx 22 + Cypress 14 + Angular 19) exists if the Angular work proves too costly.

**Tech Stack:** Nx, Angular (CLI + `@angular-devkit/build-angular:application` esbuild builder), NgRx, Jest via `@nx/jest` + `jest-preset-angular`, ESLint 9 flat config + `angular-eslint`, Cypress via `@nx/cypress`, TypeScript. Node pinned via `ui/.nvmrc`.

**Spec:** `docs/superpowers/specs/2026-08-29-cypress-nx-angular-upgrade-design.md`

## Global Constraints

- All work happens in `ui/` (the Nx workspace root). Never run these commands from the repo root.
- `nx` and every `@nx/*` package (`@nx/angular`, `@nx/cypress`, `@nx/eslint`, `@nx/jest`, `@nx/node`, `@nx/workspace`) must always be at the **exact same version** after a pass. No partial `@nx/*` bumps.
- Angular majors must be crossed **one at a time**: 19 → 20 → 21. `ng update` / `nx migrate` refuse to skip.
- End state targets: `nx`/`@nx/*` = `23.1.2`; Angular = `21` (accept `20` if `nx migrate` at 23.1.2 lands there — the hard floor is `@angular-devkit/build-angular >= 20`, which Cypress 15 support needs); `cypress` = `15.21.1`; run through `@nx/cypress@23`.
- `@nx/cypress` peer ranges: `19/20` → `cypress < 14`; `21/22` → `cypress < 15`; `23` → `cypress < 16`. Cypress may only be bumped in Task 5, after Nx is at 23.
- `@ngrx/*` has a hard `@angular/core` major peer — it moves in lockstep with Angular every pass.
- Node: `ui/.nvmrc` pinned to `22.12.0`; use that Node for every command. Angular 20/21 + `@angular/cli@20+` require `node ^20.19 || ^22.12 || >=24`.
- Each pass ends at a committable green state (verification gate passes) before the next begins.
- Intermediate versions: `nx@20.8.4`, `nx@21.6.11`, `nx@22.7.8` (fallback only), `nx@23.1.2`.
- Do not touch `src/main/java/dto/Feature.java` (unrelated pre-existing working-tree change).

## The Verification Gate

Referred to by every task. Run from `ui/`. "Green" = every command exits 0 and the smoke check passes.

```bash
npx nx reset
npx nx run-many --target=lint --all
npx nx run-many --target=test --all
npx nx build translatr --configuration production
npx nx build translatr-admin --configuration production
npx nx build lets-generate --configuration production
# Task 5 onward, also:
npx nx e2e translatr-e2e
npx nx e2e translatr-admin-e2e
```

Smoke check (manual, Task 2 onward): `npm start` → open the dashboard, a project page, the key editor; `npm run start:admin` → open the dashboard and the feature-flags page. No console errors, pages render.

Record the gate result (pass/fail per command) in the commit body for the pass.
